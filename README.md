# MikroERP — изданија

Тука стои **последната верзија** на MikroERP; апликацијата сама ја чита
од овде и се ажурира.

- Тековна верзија: **0.25.3** (2026-08-17)
- **Windows**: [MikroERP.zip](MikroERP.zip) — се отпакува и се кликнува `MikroERP.exe`
- **Linux**: [MikroERP-linux.tar.gz](MikroERP-linux.tar.gz) — се отпакува и се пушта `./mikroerp.sh` (бара `python3-tk`)
